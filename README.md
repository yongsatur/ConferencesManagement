# Десктопное приложение для менеджера конференций

[![C#](https://img.shields.io/badge/C%23-12.0-239120?style=for-the-badge&logo=c-sharp&logoColor=white)](https://docs.microsoft.com/en-us/dotnet/csharp/)
[![.NET](https://img.shields.io/badge/.NET-8.0-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)](https://dotnet.microsoft.com/)
[![WPF](https://img.shields.io/badge/WPF-.NET_Desktop-5C2D91?style=for-the-badge&logo=windows&logoColor=white)](https://docs.microsoft.com/en-us/dotnet/desktop/wpf/)

**Система управления конференциями** — это десктопное приложение на C# с использованием WPF (Windows Presentation Foundation), созданное в рамках производственной практики. Оно предоставляет менеджеру удобный инструмент для работы с конференциями.

---

## Основные возможности

- **Управление конференциями**: создание, просмотр, изменение и удаление конференций;
- **Фильтрация и сортировка**: быстрый поиск нужных событий по различным критериям;
- **Визуальный календарь**: отображение дней с запланированными конференциями, выделенных цветом на календаре.

## Технологии

Проект построен на современном стеке технологий Microsoft:

- **Язык программирования**: C#;
- **Фреймворк**: .NET;
- **Интерфейс**: WPF (Windows Presentation Foundation) с использованием XAML.
